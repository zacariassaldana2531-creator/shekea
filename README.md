# SHEKEA · Salud & Nutrición Integral

Sitio web estático de SHEKEA (Santo Domingo, R.D.). Un solo archivo, sin dependencias ni compilación.

- `index.html`: la página completa (estilos, contenido, fotos temporales y script).
- Datos de contacto y fotos: bloque `const SHEKEA = {...}` al final de `index.html`.
- Despliegue: Vercel publica automáticamente cada cambio en la rama `main`.

Pendiente antes de difundir: logo oficial, fotografías reales, confirmar WhatsApp, precios y cifras.
